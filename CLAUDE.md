# CLAUDE.md

Notes for working on this repo. User-facing docs are in `README.md`.

Tools from the 2021 PhD thesis "Coordinating the Internet" (Lindeberg). The main tool, `src/generatemap.py`, visits websites with headless Chrome, traces the route to every host they load content from, and draws which networks (AS), countries and companies the sites depend on. The code is old research code: make targeted changes and keep its style rather than refactoring broadly.

## Layout

The pipeline (`generatemap.py` → `CheckHAR.Load()` → `CheckHAR.cook()` → `getEdges()` → `draw_graph()`):

- `src/generatemap.py`: CLI entry point; elevates with sudo only if `parallelltracert.requires_root()`.
- `src/generatehar.sh`: headless Chrome + `chrome-har-capturer` → a HAR file.
- `src/harutilities.py`: HAR parsing (hosts, bytes), DNS (A, plus AAAA with `-6`), and `cook()`: resolve → trace → AS lookup → edges.
- `src/parallelltracert.py`: parallel UDP traceroute. `TraceManager` runs and caches traces; `UnprivilegedTracer` (Linux) and `RawSocketTracer` (macOS and the rest) do one trace each.
- `src/asnutils.py`: IP → AS with `pyasn`; RDAP (via ARIN) for unannounced ranges such as IXP LANs; company names via `cleanco` and `string_grouper`.
- `src/edgeutils.py`, `src/internetgraph.py`: edges, and drawing with networkx + Graphviz `neato` (png + svg).
- `tests/`: offline tests (packet parsing, hop logic, routing-data selection).

Not part of the pipeline: `rfccounter/` (RFC statistics, its own CI workflow), `zoneyoga/` (AS statistics of name servers in zone files), `pdfs/` (ICANN PDF scraper). Unused leftovers: `src/pyasn_old.*`, `src/testpyppeeteer.py`. `src/string_grouper.py` is a modified copy of the PyPI package of that name, which must not be installed as well.

## Setup, run, test

See README for Chrome, `chrome-har-capturer` and Graphviz. Python 3.13, in `.venv` (git ignored); on macOS `pygraphviz` needs `CFLAGS`/`LDFLAGS` pointing at `brew --prefix graphviz`.

    cd src
    python generatemap.py -6 -q -w www.netnod.se -o out      # full pipeline, ~30 s per few sites
    python generatemap.py -q -e out/www_netnod_se.har -o out  # from an existing HAR, no Chrome
    python parallelltracert.py                                # just traces, prints the hops
    python -m pytest ../tests                                 # offline tests
    black --check . ../tests ../pdfs                          # CI fails PRs on black

Run from `src/`: `generatehar.sh` is called as `./generatehar.sh` and writes `har_errors.log` to the working directory.

Real runs need the network: DNS, outgoing UDP probes and incoming ICMP, RDAP, and routing-data downloads. In Claude Code's sandbox those (and `git push`/`fetch` over SSH, and `gh`) have to run outside the sandbox.

## Things that are not obvious

- **Tracing without root.** Linux reads ICMP errors off each UDP socket's error queue (`IP_RECVERR`); Python < 3.14 lacks those constants, so their Linux ABI values are hard-coded as fallback. macOS listens on `SOCK_DGRAM` ICMP sockets, which unprivileged users may open and which receive the errors for our probes. Elsewhere raw sockets, i.e. root.
- **One flow per trace.** All probes of a trace share the source port, so load-balancing routers keep them on one path (as in Paris traceroute); per-probe ports gave duplicate and missing hops. Probes are told apart by payload length (= ttl). Keep both properties when changing the tracers.
- **Gap limit.** A trace stops after 5 unanswered hops in a row (`__GAPLIMIT__`).
- **Linux hop discovery is unverified** on a real network. CI's "Trace without root" step only shows `*`, because ICMP is filtered on GitHub's runners; that is not by itself a bug. macOS is verified for IPv4 and IPv6.
- **Routing data.** `src/pyasn.dat`/`.json` is a snapshot in git; `pyasn_local.*` (git ignored) is generated by `updatepyasnfiles.sh`, and whichever is newer is used, by the date in the `.dat` header. `generatemap.py` regenerates when older than `--asn-max-age` days (default 7, ~100 MB). `./updatepyasnfiles.sh pyasn` updates the snapshot.
- **Shared state.** `AsInfo`'s default dicts are shared by all instances (in effect a global cache), and `TraceManager` caches traces for the whole process.

## Git and GitHub

- Work on a branch and open a PR against `master`. `master` is protected (locked, one approving review required); the owner merges with admin rights. Only merge (`gh pr merge --admin`) when the user asks.
- Commits are signed with SSH keys through the 1Password agent, and the user has to approve each signature in 1Password. If signing fails, report it; do not commit unsigned. This clone's `.git/config` sets the signing key and email for the repo; leave it as is.
- Commit messages: short imperative subject, body explaining why.
